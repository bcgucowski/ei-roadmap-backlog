Como funciona (sem Azure AD)
  1. Hospede este arquivo no SharePoint — faça upload do HTML para a biblioteca Site Assets ou qualquer biblioteca de documentos do seu site SharePoint.
  2. Abra pelo link do SharePoint — ao abrir via URL do SharePoint (https://suaempresa.sharepoint.com/...), o SharePoint injeta automaticamente a sessão do usuário logado. Não funciona ao abrir localmente.
  3. Preencha os campos abaixo — informe a URL do site e o nome da lista. As configurações ficam salvas no seu navegador (localStorage). Clique em Salvar e depois Testar Conexão.
Conexão SharePoint
URL completa do site onde a lista foi criada. Sem barra no final.
Nome exato da lista no SharePoint (case-sensitive). Veja em: Configurações do Site → Listas e Bibliotecas.
Mapeamento de Colunas (Internal Name de cada coluna)

Informe o Internal Name de cada coluna da sua lista. Para descobrir: Configurações da Lista → clique na coluna → veja o parâmetro Field= na URL. Colunas padrão do SharePoint como Title e Created não precisam ser alteradas.
